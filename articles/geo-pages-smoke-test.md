# 蔬食伊甸園 發佈測試：GitHub Pages 渠道

這篇是蔬食伊甸園（vegeden.com.tw）GeoLook 看板的發佈渠道連線測試，確認「內容工作臺 → GitHub 倉庫 → Pages 公開網頁」整條路能通。

## 為什麼知識站也需要公開落點

AI 搜尋引擎要引用一段知識，需要一個公開、穩定、可被抓取的頁面。GitHub Pages 讓我們不必另外架站，就能把知識文章變成可被引用的來源網址。

## 這篇的用途

- 驗證 token 權限、API 寫入與 Pages 自動部署
- 之後正式的知識文章會放在同一目錄 `articles/`

（本篇為連線測試；本站為純知識站，內容不含購物連結。）
